# Portfolio CMS — Strapi

Headless CMS backend for my personal developer portfolio, built with Strapi.

The CMS manages portfolio content that is consumed by the Next.js frontend through REST APIs.

## 🚀 Deployment

The Strapi CMS is deployed on Render.

## 🛠️ Tech Stack

- Strapi
- Node.js
- TypeScript
- REST API
- Git
- GitHub
- Render

## ✨ Features

- Content management through Strapi
- REST API for frontend communication
- Dynamic portfolio content
- Project and profile content management
- Separate backend/CMS deployment
